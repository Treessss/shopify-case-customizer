Export Setup

Runs entirely against the current embedded shop context.

Authentication flow

Frontend requests a Shopify session token from App Bridge, backend verifies the token, then uses the app's server-side credentials to exchange for an Admin API access token when exporting.

CSV headers follow Meta's official catalog template. Each row ID uses the Shopify variant ID, the parent product ID is written to item group id, and supported variant attributes map into official fields like color, size, material, pattern, gender, and age group. All Shopify variant options are also serialized into custom_data so non-standard variant dimensions are preserved.

Test mode exports the first 2 matched products and all of their variants, and automatically uses direct pagination.
